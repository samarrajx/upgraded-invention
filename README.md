# AI Engineer Career OS (v2.0) 🚀

A modular, offline-capable Progressive Web App (PWA) designed to gamify and track the journey from scratch to AI Engineer.

![Career OS Dashboard](https://raw.githubusercontent.com/samarrajx/upgraded-invention/main/assets/icon-512.png)

## ✨ Features
- **Gamified Progress**: Earn XP for every task, level up your profile, and unlock badges.
- **Offline-First**: Built with Service Workers to work perfectly without an internet connection.
- **Modular Roadmap**: A comprehensive 1-year curriculum covering Python, DSA, Math, and Projects.
- **Interactive Focus Mode**: Clear the noise and focus on today's high-priority tasks.
- **Glassmorphic UI**: Beautiful, modern interface with dark mode and smooth animations.
- **Data Privacy**: All progress is stored locally in your browser's `localStorage`.

## 🛠️ Tech Stack
- **Core**: Vanilla JavaScript (ES6 Modules)
- **Styling**: Modern CSS3 (Glassmorphism, Flexbox/Grid)
- **State**: Custom `localStorage` store engine
- **PWA**: Service Worker + Manifest.json

## 🚀 Deployment
The app is automatically deployed to GitHub Pages.
View it here: **[https://samarrajx.github.io/upgraded-invention/](https://samarrajx.github.io/upgraded-invention/)**

## 📂 Project Structure
- `/js/views`: Individual page components (Dashboard, Roadmap, etc.)
- `/js/store.js`: Central state management and persistence.
- `/js/gamification.js`: XP logic, badges, and streaks.
- `/css`: Modular styles (tokens, components, layout).
- `/assets`: PWA icons and brand assets.

## 📝 Usage
1. Open the app.
2. Complete tasks on the **Roadmap** or **Focus** tabs.
3. Your XP and Level will update automatically.
4. Export your data in **Settings** for backups.
